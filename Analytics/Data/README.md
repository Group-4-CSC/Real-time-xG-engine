# Statsbomb Data

**Database Information**
- To download the Statsbomb data go here: https://github.com/hudl/open-data
- Create a folder called Data/Raw_Statsbomb_Data/ then create two more folders CL_Final_Match_Data and CL_Final_Shot_Data insert match and shot data.
- Run Data_Cleaning.py
- Credit to Statsbomb for providing the data for our project.
